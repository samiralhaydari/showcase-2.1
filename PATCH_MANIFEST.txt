MYR SupplyLens V2.1.1 patch manifest
=====================================

This is a runtime-safe repackaging of the V2.1 source patch. It preserves the
V2.1 benchmark-aware forecasting logic and replaces the Colab dependency
strategy/documentation. It does NOT contain or overwrite trained model weights,
scalers, raw/processed data, SQLite records, supplier records or invoice records.

Runtime safety guarantees:
- No programmatic runtime restart or kernel shutdown API.
- No process-kill fallback (no os.kill or SIGKILL).
- No TensorFlow installation or forced replacement in Colab.
- Dynamic pip constraints preserve the core package versions already present.
- The notebook stops if core package versions change unexpectedly.

V2.1 model outputs continue to use _v2_1_ filenames. Existing V2/V1 artifacts
remain available as inference fallbacks.
